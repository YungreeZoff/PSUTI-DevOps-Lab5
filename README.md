# Лабораторная работа №5. Вариант 20

## Описание
Веб-интерфейс для демонстрации механизма идемпотентности при бронировании событий. 
Приложение показывает, что повторная отправка запроса с тем же ключом идемпотентности возвращает существующую бронь, а изменение тела запроса с тем же ключом вызывает ошибку конфликта (HTTP 409).

## Запуск
Для запуска приложения выполните в корне проекта:
```bash
docker compose up -d --build
